# Математическая статистика — лабораторные работы

Сборник лабораторных работ по курсу математической статистики. Каждая работа оформлена в виде Jupyter-ноутбука по единому шаблону:

1. **Заголовок и тема** работы.
2. **Постановка задачи** — что и зачем проверяется.
3. **Разделы** с кодом, разбитым на логические ячейки и сопровождённым markdown-заголовками.
4. **Выводы** — интерпретация полученных результатов.

> Работы предназначены как образец оформления. Все ноутбуки воспроизводимы: генерация случайных данных зафиксирована через `np.random.seed(42)`.

## Содержание

| № | Папка | Тема |
|---|-------|------|
| 1 | [lab-1](lab-1/notebook.ipynb) | Первичная обработка выборки: интервальный статистический ряд, гистограмма, эмпирическая функция распределения, выборочные характеристики и устойчивость оценок к выбросам |
| 2 | [lab-2](lab-2/notebook.ipynb) | Доверительные интервалы для параметров нормального распределения (негруппированные и группированные данные) и асимптотические интервалы для распределений Бернулли, Пуассона, показательного |
| 3 | [lab-3](lab-3/notebook.ipynb) | Ядерные оценки плотности, выборочная корреляция с доверительным интервалом (преобразование Фишера), линейная регрессия при разных типах шума |
| 4 | [lab-4](lab-4/notebook.ipynb) | Проверка статистических гипотез: корреляция, t-критерий Стьюдента (независимые и связанные выборки), критерий Фишера, однородность пуассоновских выборок |
| 5 | [lab-5](lab-5/notebook.ipynb) | Критерии согласия и однородности: Пирсона ($\chi^2$), Колмогорова и Колмогорова–Смирнова, критерий знаков, критерий Вилкоксона (Манна–Уитни) |
| 6 | [lab-6](lab-6/notebook.ipynb) | Проверка автокорреляции (критерий по коэффициенту автокорреляции и критерий Морана) и проверка сдвига дисперсии по критерию Хсу |

## Зависимости

```
numpy
scipy
matplotlib
seaborn   # используется в lab-5
pandas    # используется в lab-4
```

Установка:

```bash
pip install numpy scipy matplotlib seaborn pandas jupyter
```

## Запуск

Открыть любой ноутбук в Jupyter / VS Code и выполнить ячейки по порядку:

```bash
jupyter notebook
# или
jupyter lab
```

Воспроизвести вывод из командной строки без запуска интерфейса:

```bash
jupyter nbconvert --to notebook --execute --inplace lab-1/notebook.ipynb
```
