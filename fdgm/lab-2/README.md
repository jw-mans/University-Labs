# Лабораторная работа №2 — разностные схемы для параболических уравнений

Краевая задача третьего рода для уравнения теплопроводности

- $\frac{du}{dt} - ρ(x)\frac{d^2}{dx^2} = f(x,t)$, 
    - $x ∈ [0,2]$,  
    - $0 ≤ t ≤ T;$
- $u(x,0) = φ(x)$;
- $-α_a u_x(0,t) + β_a u(0,t) = γ_a(t)$;
- $α_b u_x(2,t) + β_b u(2,t) = γ_b(t)$.

Данные: 
- $ρ(x) = 1 + \sin²(\frac{\pi x}{2})$ 
    - $ρ_{\min} = 1$, $x_{\min}=\arg\min\limits_{x\in[0; 2]}\rho(x)\in\{0; 2\}$,
    - $ρ_{\max} = 2$, $x_{\max}=\arg\max\limits_{x\in[0; 2]}\rho(x)=1$, 
- $α_a = β_a = α_b = 1$, 
- $β_b = 2$

Точное решение построено подстановкой: $u^*(x,t) = v(x,t)·w(x)$, где
$v(x,t) = p(x)e^{-kt} + 1$, $p(x) = 1 + x/2$, $k = 3$, а $w(x) = x \sin{2πx} + e^{-x}$
— решение из работы 1. При $t → ∞$ имеем $u^* → w(x)$.

Счёт ведётся до момента установления $\texttt{ust}$, определяемого из
$\frac{‖u(·,t) − w‖}{‖w‖} ≤ δ$, $δ = 10⁻³$.

Реализованы три схемы: явная, неявная, симметричная (Кранка — Николсон).

## Файлы

    code/problem.py    постановка: ρ, w, p, u*, f, φ, γ_a(t), γ_b(t), момент установления
    code/schemes.py    прогонка, аппроксимация краевых условий, три схемы
    code/run.py        все расчёты задания, таблицы в консоль, графики
    code/anim.py       визуализация счёта в реальном времени (задание 1б)
    report/report.tex  отчёт (pdfLaTeX)
    report/figures/    графики

## Запуск

Расчёты и графики:

    python code/run.py

Печатает все таблицы отчёта и пересобирает `report/figures/*.pdf`.
Полный прогон занимает несколько минут.

Визуализация в реальном времени:

    python code/anim.py                       явная схема, M0, τ = τ0
    python code/anim.py --scheme implicit     неявная схема
    python code/anim.py --mult 1.02           явная схема за порогом устойчивости
    python code/anim.py --save evolution.gif  записать анимацию в файл

На экране одновременно текущее численное решение и установившееся `w(x)`.

Нужны `numpy` и `matplotlib`.

Отчёт компилируется в Overleaf: загрузить папку `report/` целиком.
